# Tic-Tac-Toe

A classic Tic-Tac-Toe game built with React, TypeScript, and Vite.

## Features

- Two-player game (X and O)
- Detects and announces the winner
- Move history with time travel — jump back to any previous move in the game

## Tech Stack

- React
- TypeScript
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
